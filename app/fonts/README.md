# Fonts

Latin subsets, self-hosted and loaded with next/font in `app/layout.tsx`.

| File | Family | Licence |
|---|---|---|
| `manrope-latin-wght-normal.woff2` | Manrope (variable) | SIL Open Font License 1.1 |
| `cormorant-garamond-latin-600-normal.woff2` | Cormorant Garamond 600 | SIL Open Font License 1.1 |
| `cinzel-latin-700-normal.woff2` | Cinzel 700 | SIL Open Font License 1.1 |

Taken from the Fontsource packages (`@fontsource-variable/manrope`, `@fontsource/cormorant-garamond`,
`@fontsource/cinzel`). Add another weight or a `latin-ext` file here if the design needs it.
